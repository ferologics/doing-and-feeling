# field

A people-centred map of consciousness science and AI-consciousness research, and a watch on what those people
publish. Direction in `VISION.md`, next steps in `TODO.md`.

## Files

```
people.toml        seed researchers: camps, crux answer (with source), pinned OpenAlex author IDs
authors.json       resolved OpenAlex profiles (generated by resolve.py)
map.md, map.html   co-authorship map: camps, strongest links, bridges, isolated people (generated by map.py)
digests/<date>.md  watch digests: new works by people on the map, links checked (generated by watch.py)
watch-state.json   date of the last watch run
scripts/           openalex.py (shared client + cache), resolve.py, map.py, watch.py
cache/             OpenAlex responses (gitignored)
```

## Commands

Run inside `field/`, or from the repo root as `just field <recipe>`.

```bash
just resolve    # match people.toml to OpenAlex authors → authors.json (pinned IDs are kept)
just map        # co-authorship map → map.md + map.html (works since 2010, cached)
just watch      # digest of new works since the last run → digests/<today>.md
```

OpenAlex needs a free API key ($1/day budget, https://openalex.org/settings/api) in the `OPENALEX_API_KEY`
environment variable.

## Adding people

Add a `[[person]]` block to `people.toml` with `name` and `camps`, plus `hint` if the name is common. Run
`just resolve`, check any match it flags, and pin the ID with `openalex = "A…"`. Set `crux` only together with
`crux_source`.
